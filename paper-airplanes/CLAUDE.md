# Paper Airplanes — Claude Code pointer

Purpose: fold-on-the-line paper airplane sheets for Felix. Each sheet is printed true to scale (no "fit to page"), two-sided, and the printed lines *are* the folds: follow the steps on the paper itself and it becomes the plane. Start with the classic planes and a research folder on how planes fly. Every plane is test-folded, flown and approved before it counts.

- Design: `schematic.md` (round 1 draft, waiting on `convo/convo v0.1.md`)
- Research: `research/topics.md`
- Q&A history: `convo/` (never compact; start a new version instead)
- AI notes: `04 AI/brief.md` and `04 AI/lessons.md`
- Shared conventions: the Index repo's root `CLAUDE.md` (public repo, privacy) and its `02 Refs/Skills/`

Rules:
- **No database.** Everything is plain files; flight tests are recorded in the repo.
- Print at 100% (actual size). A ruler check on every sheet proves the scale.
- A plane is "approved" only after a real fold and flight test.
- Felix's first name only; no age, school or photos. Photos of real folds go in `private/` (ignored).
- Self-contained folder, so it can become its own repo later.
- Not built yet: round 1 is the schematic and the questions.
